## English

Small scripts and tips I use to solve everyday problems (files, backups, automation, etc.). Shell, Python, and whatever else does the job.

### Structure

Scripts are grouped by topic, not by language:

```
tips-and-scripts/
├── files/
├── network/
├── backups/
└── misc/
```

### Scripts

| Script | What it does |
|--------|--------------|
| `files/example.sh` | Short description |

### Usage

Each script starts with a comment that explains what it does and how to run it.

```bash
chmod +x script.sh
./script.sh
```

### Disclaimer

Read a script before running it. Use at your own risk, and test on a copy of your data first.

Ideas and fixes are welcome: open an issue or a pull request.
