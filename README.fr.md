# tips-and-scripts

🇬🇧 [English](README.md) | 🇫🇷 Français

Petits scripts et astuces que j'utilise pour régler des problèmes du quotidien (fichiers, sauvegardes, automatisation, etc.). Shell, Python, et tout ce qui fait le travail.

## Organisation

Les scripts sont rangés par thème, pas par langage :

```
tips-and-scripts/
└── macos/
    └── copy-chrome/
```

## Scripts

| Script | Ce qu'il fait |
|--------|---------------|
| [`macos/copy-chrome`](macos/copy-chrome/README.fr.md) | Crée une copie de Google Chrome par compte Google sur macOS, chacune avec son icône dans le Dock et son entrée dans Cmd+Tab. |

## Utilisation

Chaque script commence par un commentaire qui explique ce qu'il fait et comment le lancer.

```bash
chmod +x script.sh
./script.sh
```

## Avertissement

Lis un script avant de le lancer. Utilisation à tes risques, et teste d'abord sur une copie de tes données.
